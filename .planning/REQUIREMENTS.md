# Requirements

## v1 Requirements

### UI & Aesthetics (UI)
- [ ] **UI-01**: Replace "Liquid Glass" floating navigation with an organic "pill" or "brush-stroke" design. Use warm backgrounds and subtle transitions.
- [ ] **UI-02**: Set site-wide primary background for the menu to "Warm White" (#FFFFFF/Bianco Carta) with a soft texture feel.
- [ ] **UI-03**: Remove tech-heavy gradients and intense neo-glass shadows from interactive elements.

### Storytelling & Content (STORY)
- [ ] **STORY-01**: Implement a narrative introduction section above the menu list (e.g., "Accomodatevi al nostro tavolo...").
- [ ] **STORY-02**: Add an evocative Bento-style image layout at the start of the menu (e.g., table imbandito, Greek chairs).
- [ ] **STORY-03**: Integrate organic micro-details like watercolor olive branch separators or wavy line dividers.

### Design System & Typography (STYLE)
- [ ] **STYLE-01**: Use primary brand colors (Blu Egeo #4B9CD3 and Rosso Corallo #D14638) for category titles and highlight states.
- [ ] **STYLE-02**: Apply Serif font (Marcellus/Greek Modern) to all <h1> and category headers.
- [ ] **STYLE-03**: Ensure text uses Grigio Ardesia (#2F4F4F) for optimal readability on warm backgrounds.

### Layout & Rhythm (PACE)
- [ ] **PACE-01**: Optimize padding and margins between menu categories (Antipasti, Secondi, etc.) to create a relaxed "reading rhythm".
- [ ] **PACE-02**: Ensure the menu is fully responsive, maintaining the "organic" feel on mobile/tablet.

## v2 Requirements (Deferred)
- [X] **i18n-EN**: Complete English translations for all menu items. (Handled during v1 or deferred based on current assets).

## Out of Scope
- Full site redesign (focus only on menu-related areas).
- Interactive ordering or booking widgets (unless simple links).

## Traceability
- **Phase 1**: STYLE-01, STYLE-02, STYLE-03, PACE-01, UI-02
- **Phase 2**: UI-01, UI-03, STORY-03
- **Phase 3**: STORY-01, STORY-02, PACE-02
